# Food API Explorer
React • JavaScript • Public API • Modern Front‑End Development

A clean and interactive React application built to explore how front‑end components communicate with external APIs.
This project was created early in my learning journey to practice API integration, state management, dynamic rendering, and modern React development patterns.

--- 

## Overview
Food API Explorer allows users to search for meals, view recipe details, and explore ingredients using data fetched from a public food API.

The application demonstrates:
- how React components interact with external APIs
- how to manage state using hooks
- how to render dynamic UI based on API responses
- how to structure a modern React project

This project marks an important milestone in my transition from basic JavaScript to modern front‑end frameworks.

---

## Features
### Search & Discover
- Search meals by name or keyword
- Fetch real‑time recipe data from a public API
- Display results as responsive recipe cards

### Recipe Details
- Meal image
- Ingredients list
- Cooking instructions
- Category & origin (if available)

### React Functionality
- Functional components
- Hooks (useState, useEffect)
- Fetch API integration
- Conditional rendering
- Component‑based architecture

### UI & Design
- Responsive layout
- Clean card‑based design
- Smooth dynamic rendering
- Vanilla CSS styling

## Installation & Setup
Clone the repository:
```
git clone https://github.com/Lavinia-81/Food-Recipe-Finder.git
cd Food-Recipe-Finder

Install dependencies:
npm install

Run the development server:
npm start

The app will be available at:
http://localhost:3000
```

---

## How to Use
- Open the application in your browser.
- Type a food name or keyword into the search bar.
- Click Search.
- Browse the list of meals returned by the API.
- Click on a meal to view detailed recipe information.
